# 相变能量系统

相变能量系统是 BreakdownKernel 的动力框架。所有机器使用统一的能量单位 —— **相变能（Phase Energy, PE）**。

> 能量 API 正在开发中，以下为设计规划。

## 核心概念

- **能量单位**：Phase Energy（PE），所有设备统一使用
- **传输方式**：基于服务注册的能量网络，支持有线和无线传输
- **能量存储**：内置能量存储器，支持多方块共享能量池

## 三种角色

| 角色      | 职责                |
|---------|-------------------|
| **生产者** | 产出能量（如发电机、太阳能板）   |
| **消费者** | 消耗能量（如机器、工具充电站）   |
| **存储**  | 同时生产和消费（如电池、能量核心） |

## 能量网络

- **自动注册**：设备放置时自动加入能量网络，破坏时自动注销
- **增量计算**：每 tick 仅计算变化的节点，避免全量遍历
- **背压控制**：需求超出供给时自动限流，保证 TPS 稳定
